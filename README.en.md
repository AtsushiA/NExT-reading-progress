# NExT Reading Progress

A WordPress Gutenberg block plugin that displays a reading-progress bar for the whole page's scroll depth.

## Features

- Implemented as a **dynamic block** (`next/reading-progress`) that renders exactly where it's placed (it does not use `position: fixed` etc. on its own — apply fixed positioning in your theme's template if you need it)
- Progress is calculated from the whole page's scroll amount (including header/footer)
- Works anywhere a block can be inserted: posts, pages, template parts, and more
- Multiple instances on the same page stay in sync
- Scroll detection and DOM updates use the [WordPress Interactivity API](https://developer.wordpress.org/block-editor/reference-guides/interactivity-api/)

### Configurable options

| Setting | Description |
| --- | --- |
| Width | Numeric value (px, %, em, rem, vw), combinable with the block's standard alignment (content/wide/full) |
| Bar thickness | Numeric value (px, em, rem) |
| Progress bar color | Solid color or gradient |
| Track (unfilled) color | Solid color |
| z-index | Numeric (optional) |

The block sets `role="progressbar"` / `aria-valuemin` / `aria-valuemax` / `aria-valuenow`, and the value updates reactively as the user scrolls.

## Requirements

- WordPress 6.8 or later
- PHP 7.4 or later

## Installation

### Using a release build

1. Place the zip generated by `npm run plugin-zip`, or the built plugin directory as a whole, under `wp-content/plugins/`
2. Activate **NExT Reading Progress** from the WordPress admin Plugins screen

### Building from source

```bash
cd wp-content/plugins/NExT-reading-progress
npm install
npm run build
```

Sources under `src/` are built into `build/`. The plugin bootstrap (`next-reading-progress.php`) loads from `build/`.

## Usage

1. In the block editor, search for "Reading Progress Bar" in the block inserter
2. Adjust width, bar thickness, colors (fill/track), and z-index from the block's Inspector Controls in the sidebar
3. To place it at the top of every page, insert the block into a template part via the Site Editor

```
│   ├── style.scss / editor.scss
│   └── index.js

```
